# v0.1 Release Freeze

This release captures the first reproducible local-first lifelog RAG workflow.
It is intended as a private working baseline and a public portfolio milestone.

## Feature Set

- Local ingestion for photos, LINE exports, GPS metadata, and call logs.
- SQLite storage with `media_items`, `line_messages`, `media_vlm`,
  `media_embeddings`, `media_ocr`, `events`, and `event_evidence`.
- Qwen3-VL image meaning extraction.
- Qwen3-VL-Embedding multimodal image retrieval.
- OCR engine integration.
- Date QA, image QA, place QA, and monthly summaries.
- VLM review overrides.
- Private eval and batch QA.
- Public/private Markdown reports and public portfolio HTML.

## Verification Commands

```bash
conda run -n personal_lifelog_rag pytest
conda run -n personal_lifelog_rag python -m personal_lifelog_rag.app.cli db-check --strict
conda run -n personal_lifelog_rag python -m personal_lifelog_rag.app.cli eval-private --path private_eval/questions_20241224.yaml --save-run
conda run -n personal_lifelog_rag python -m personal_lifelog_rag.app.cli build-portfolio-html --mode public --check-privacy --force
python scripts/check_public_portfolio_safety.py reports/portfolio_public.html
```

## Success Conditions

- Test suite passes.
- Strict DB check passes.
- Private eval is saved, with failures recorded rather than hidden.
- Public portfolio HTML privacy check passes.
- Release manifest is written to `reports/release_v0_1_manifest.json`.

## Recovery

- Before DB-changing operations, run `backup-db`.
- Use `missing-files` to diagnose unavailable source media.
- Use `retry-vlm-failed`, `retry-ocr-failed`, and `retry-embedding-failed`
  with `--dry-run` before any retry.
- Use `db-check --strict` after maintenance.

## Public And Private Artifacts

Private data and private eval files stay local. Public reports and portfolio
HTML must avoid raw messages, exact coordinates, real photos, personal names,
runtime secrets, and local absolute paths.

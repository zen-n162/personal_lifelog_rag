# v0.1.1 Stabilization Patch

v0.1.1 stabilizes the v0.1 release after the 2025-03 monthly rollout. The
patch does not rerun the heavy 2025-03 analysis. It fixes evaluation
expectations, retries a small set of failed rows, records missing-file
maintenance, and regenerates the public portfolio artifacts.

## What Changed

- Private eval now treats the stage-photo regression as a 2024-12 scoped case.
- VLM quality evaluation allows `json_repaired` as an accepted recovery flag.
- VLM failed retry recovered 4 of 20 selected failed rows.
- OCR failed retry saved 5 successful OCR rows.
- Missing originals were exported to CSV and marked unavailable for future
  analysis selection without deleting media records.
- v0.1.1 release manifest, public/private reports, and portfolio HTML were
  regenerated.
